# AI Pair Programming Plugin Demo V2

This is the interactive web demo for Scenario 1 of the HAII research project.

**Full setup instructions are in the root README:** https://github.com/schoenthaler/HAII

---

## Quick start (if you've already done the one-time setup)

```
pnpm dev
```

Open **http://localhost:5173** in Chrome or Edge.

---

## Environment variables

Create a `.env` file in this folder (copy from `.env.example`):

```
VITE_GROQ_API_KEY=your_groq_key      # AI chat — free at console.groq.com
VITE_GEMINI_API_KEY=your_gemini_key  # AI voice — free at aistudio.google.com
```
